# ストア・事業者・運営画面のリサーチ

調査日：2026-10-11。これは再設計のための調査と提案であり、実装済み機能の一覧ではありません。
Amazon風の濃紺・白／薄いグレー・オレンジを共通テーマとする。ロゴ・文言・固有の装飾を複製する方針ではない。

Amazonの購入者向けトップ・ヘルプはアクセス制限／代替ページのため、本調査では実際の全画面を確認できなかった。
購入者画面のAmazon風レイアウトは利用者の指定に基づく設計案であり、取得した公式資料の仕様と混同しない。

## 推奨するページ構成

| 利用者     | ページ                   | 主な責務                                               |
| ---------- | ------------------------ | ------------------------------------------------------ |
| カスタマー | ストアホーム・商品検索   | 大きな検索バー、商品画像・名称・価格、商品詳細への入口 |
| カスタマー | 商品詳細                 | 商品画像、販売元、価格、数量選択、カート追加           |
| カスタマー | カート                   | 明細・数量変更・削除・小計、購入手続きへの入口         |
| カスタマー | 購入確認・注文完了       | 価格・在庫の再確認、注文確定、結果と注文詳細への入口   |
| カスタマー | 注文履歴・注文詳細       | 自分の注文だけの一覧・状態・許可された取消             |
| 企業       | ダッシュボード           | 自社の状況、対応が必要な注文、専用一覧への入口         |
| 企業       | 注文一覧・注文詳細       | 絞り込み、明細確認、権限と状態に応じた操作             |
| 企業       | 商品一覧・商品登録／編集 | 商品・価格・画像を管理。注文操作を混在させない         |
| 企業       | メンバー・企業設定       | 所属、ロール、招待。販売業務とは別ページ               |
| 運営       | ダッシュボード           | 企業・利用者の状況、対応対象への入口                   |
| 運営       | 企業一覧・企業詳細       | 作成・停止、招待許可、企業単位の設定                   |
| 運営       | ユーザー一覧・詳細       | サービス別の会員、権限に応じた個人情報・停止操作       |
| 運営       | アクセス・プラン設定     | ロール・プラン権限・企業IP設定を目的別に配置           |

## 実装前に解決する制約

現行の商品一覧・画像APIは認証済みのcustomer/businessと権限を要求する。
現行カスタマーホームは所属企業の選択入口で、一般ユーザーが商品を探すストアではない。
公開の商品カタログと、企業に所属しない購入者が販売元の商品を買うルールは、既存の所属ガードを外すだけでは実現しない。
公開する商品・画像の範囲、販売元の有効状態、購入者の登録、注文所有、販売元の在庫・価格照合を別々に定義する必要がある。

初期改修は現在の商品・価格・画像・注文状態を利用する。レビュー、ランキング、送料、住所、配送追跡、
実決済、広告、クーポンはデータモデルと業務ルールが必要なため、見た目だけの機能として置かない。
ダッシュボードの未出荷件数や売上等を表示する場合は、全対象を正しく集計するAPIと定義を用意する。

## レイアウトと実装の基準

購入者は濃紺のヘッダー、大きい検索、カート・注文履歴、商品を主役にした白いカードを使う。
企業・運営はサイドナビ、パンくず、ページ見出し、概要カードと表を使い、同じテーマでも作業密度を変える。
モバイルではナビゲーションを折り畳み、購入操作と一覧操作を狭い画面でも使えるようにする。
色はライト／ダーク両方の意味付きトークンで管理する。

既存のDDD・FSD、shadcn/ui、一ファイル一コンポーネント、日本語原文のi18next、Storybook、
SuspenseとSkeleton、公式Error Boundary、Zodのパス検証、APIの認証・認可・テナント分離を維持する。
ページは接続と表示の組み立てに限定し、業務変換はentities、操作はfeatures、画面のまとまりはwidgetsが所有する。
